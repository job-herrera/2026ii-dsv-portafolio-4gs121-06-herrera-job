# Práctica 4 — Formulario

**Sitio de la Clínica Veterinaria ConSentidos**

Formulario de solicitud de cita (`cita.html`) con validación nativa del navegador: campos de texto, correo, teléfono, número, fecha, hora, selección, casillas, botones de opción, rango y archivo.

**Autor:** Job Herrera · 4GS121-06
**Curso:** Desarrollo de Software V · Universidad Tecnológica de Panamá, Centro Regional de Veraguas

La validación del navegador ayuda a quien llena el formulario, pero no protege los datos: la validación de seguridad se hace en el servidor.
